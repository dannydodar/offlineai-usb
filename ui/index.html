These controls are optional. The assistant is ready to chat using sensible settings. Change something only when you know what you want it to do.

Model and speed

The model is the local AI brain. Qwen3 0.6B is the small emergency option for very limited laptops. E2B is stronger and E4B is strongest, but both need more memory. The selected model may be copied to this computer for better speed.

Need the super-light model? Download Qwen3 0.6B directly from the model host. It is about 429 MB and is checked before installation.

PDF library

When enabled, the assistant searches the local PDFs only when you explicitly mention PDFs, books, manuals, documents, sources, or ask it to look something up in the library. Ordinary questions do not search anything.

Answer and memory limits

These are advanced limits. If the laptop feels slow, lower the context window or maximum response tokens. Temperature changes how creative the answer feels; Top P is another sampling limit and can normally stay at its default.

Software and privacy

This assistant runs locally. Your chat and PDFs are not sent to an online AI service. Software updates come from the configured public GitHub repository.
